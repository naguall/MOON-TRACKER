# 🌙 Moon Tracker

**Complete Lunar Calendar with Planetary Aspects, Personal Journal & Automatic Notifications**

---

## 🌟 Features

### 📅 Three Calendar Modes
- **Lunar Calendar** - Based on moon phases (29.5 day cycles)
- **Solar Calendar** - Astrological signs (30-day cycles)
- **Gregorian Calendar** - Traditional monthly view

### 🌙 Lunar Phases
- Exact times for New Moon, Full Moon, Quarter Moons
- Daily moon phase tracking
- Lunar day counter

### ⭐ Planetary Aspects
- Interplanetary aspects (conjunctions, oppositions, trines, squares, sextiles)
- Planet sign changes (Venus → Aries, Mars → Leo, etc.)
- Retrograde periods
- Detailed interpretations for each aspect

### 📝 Personal Journal
- Daily diary entries
- Voice dictation support
- Auto-save functionality
- Synchronized across all three calendars

### 📅 Events System
- Add personal events to any date
- Mark events as complete
- Persistent storage

### 🔔 Automatic Notifications
- Scheduled messages for lunar phases
- Planetary aspect reminders
- Personal reflection prompts
- Customizable message schedule

### 🌐 Multi-language Support
- English / Español
- Easy language switching

### 📱 Progressive Web App (PWA)
- Install on any device
- Works offline
- Push notifications
- App-like experience

## 📦 Installation

### Option 1: Use Online (No Installation)
Just visit the URL above and start using it.

### Option 2: Install as App
1. Visit the website on Chrome/Edge/Safari
2. Click the "Install App" button or use browser menu
3. App will be added to your device
4. Access offline anytime

### Option 3: Run Locally
```bash
git clone https://github.com/naguall/MOON-TRACKER.git
cd MOON-TRACKER
# Open index.html in your browser
```

## 🎯 How to Use

### Calendar Navigation
- **Month Arrows** - Navigate between months
- **Mode Buttons** - Switch between Lunar/Solar/Gregorian
- **Language Toggle** - Switch between English/Spanish

### Adding Journal Entries
1. Click on any day
2. Modal opens with diary section
3. Type or use voice input (microphone button)
4. Auto-saves as you type

### Adding Events
1. Click on any day
2. Add event in the events section
3. Events persist across browser sessions

### Notifications
1. Click the bell icon (🔔)
2. Allow notifications when prompted
3. Receive automatic messages at scheduled times
